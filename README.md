# <h2>ArcGIS Sandbox</h2>  🌍

Este repositório tem como objetivo documentar, guiar e demonstrar o processo de criação e acesso às contas de **Sandbox ** na plataforma ArcGIS (Esri). 

O foco aqui é centralizar o conhecimento prático para desenvolvedores e analistas que precisam de um ambiente seguro  e explorar as capacidades de geoprocessamento da plataforma sem impactar ambientes de produção.

---

## 🚀 Objetivo do Repositório

* **Guiar o Acesso:** Apresentar o passo a passo para criar e configurar uma conta no *ArcGIS

---

## 🔐 Como Funciona o Acesso à Sandbox X

O ambiente de Sandbox do ArcGIS é obtido através do programa de desenvolvedores da Esri. Abaixo estão as etapas principais para o acesso:

### 1. Criação da Conta
1. Acesse o portal do  [ArcGIS].
2. Preencha os dados e confirme a ativação pelo e-mail.
